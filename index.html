What is accentists?

Accentists is a lightweight custom wallpaper engine that allows you to display a custom wallpaper on your desktop.

The included Accentist utility makes it simple to customize Windows accent colors from an easy-to-use interface.

The project is designed to be lightweight, portable, configurable, and easy to use.

Features

  • Custom wallpaper engine
  • Windows accent color customization
  • Automatic startup support
  • PNG, JPG, JPEG and WEBP support
  • Lightweight and easy to configure
  • Open source on GitHub

Open Source

Accentists and Accentist are open-source projects hosted on GitHub. You can inspect the source code, report issues, suggest improvements, or contribute directly to development.
