What is Wallppr?

Wallppr is a lightweight custom wallpaper engine that allows you to display a custom wallpaper on your desktop. The included Accentist utility makes it easy to customize Windows accent colors from a simple interface.

The project is designed to be simple, portable, and easy to configure.

Features

  • Custom wallpaper engine
  • Windows accent color customization
  • Automatic startup support
  • PNG, JPG, JPEG, and WEBP image support
  • Lightweight and easy to configure
  • Open source on GitHub
